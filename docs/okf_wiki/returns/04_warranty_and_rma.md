# Product Return & Warranty Guidelines

## 📖 Executive Summary
Comprehensive hardware return policy, limited 1-year warranty coverage, and Return Merchandise Authorization (RMA) procedures compliant with the FTC Magnuson-Moss Warranty Act.

## 💡 Core Knowledge & Technical Specifications
- **30-Day Return Window**: Customers may return unopened or defective hardware within 30 days of delivery for a full refund or free replacement.
- **1-Year Limited Warranty**: Covers manufacturer hardware defects, power supply failures, and internal component faults for 12 months from purchase date.
- **RMA Process**: Contact support to receive an RMA number. Package unit securely and ship using prepaid shipping label provided by logistics.
